# Decisions

Architecture and product decisions, one file each, so they're made once and not re-argued in chat.

- **Name:** `NNNN-short-title.md`, numbered in order (`0002-auth-provider.md`).
- **Sections:** Status (Proposed, Accepted, or Superseded by NNNN), Date, Context, Decision, Why, Alternatives considered, Consequences.
- **Changing a decision:** don't edit the old file's decision. Write a new one and mark the old one "Superseded by NNNN".
