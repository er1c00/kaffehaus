# Research

Findings from web and market research, one file per topic, so nobody researches the same question twice.

- **Name:** `<topic-slug>.md`, and `<idea-slug>-evaluation.md` for idea evaluations from `/studio:evaluate`.
- **Contents:** the question, a short answer, findings with source links and the date checked, and a "What I couldn't confirm" section.
- **Freshness:** prices, versions, and competitors change. Check the date before relying on a finding.
